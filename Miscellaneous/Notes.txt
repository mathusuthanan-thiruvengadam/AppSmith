* closing Claude
* restarting Claude
* shutting down the laptop
* power cycling the laptop
* starting a new Claude session
* continuing the project weeks or months later

Please set up a robust project-memory system for this project.

IMPORTANT:

* Do not modify my existing global Claude skills/plugins configuration.
* Do not move, copy, or reinstall my global Claude skills/plugins.
* Do not create unnecessary plugin-specific structures.
* This is a project-level persistent knowledge system.
* Use ordinary Markdown files so I can read them myself in VS Code or any text editor.
* Preserve information carefully; do not silently discard previous decisions or ideas.

Create this structure in the current project:

project-memory/
PROJECT.md
REQUIREMENTS.md
DECISIONS.md
BRAINSTORMING.md
OPEN-QUESTIONS.md
IDEAS.md
SESSION-LOG.md

Also create a project-level CLAUDE.md in the project root.

The structure should have these purposes:

1. PROJECT.md
   Maintain the current high-level understanding of AppSmith:

   * project purpose
   * problem being solved
   * target users
   * project vision
   * current direction
   * current status
   * important constraints
   * important assumptions

   Maintain requirements discovered during the project.

   * confirmed requirements
   * tentative requirements
   * functional requirements

   Maintain important decisions.
   For every significant decision record:

   * date/session
   * decision

   * reason/rationale
   * alternatives considered
   * why alternatives were rejected
   * consequences/trade-offs
   * current status

   Never silently replace an old decision.
   If a decision changes, preserve the historical decision and record the new decision as a change/superseding decision.

4. BRAINSTORMING.md
   Maintain important brainstorming discussions and conclusions.
   Capture ideas that came from exploration even if they have not yet become requirements or decisions.

5. OPEN-QUESTIONS.md
   Maintain unresolved questions, uncertainties, things requiring investigation, and decisions that have not yet been finalized.

6. IDEAS.md
   Maintain potentially useful ideas that are not currently part of the implementation plan.
   Do not lose good ideas simply because they are postponed.

7. SESSION-LOG.md
   Maintain a chronological summary of significant Claude sessions.
   For every significant session record:

   * date
   * objective
   * important topics discussed
   * important conclusions
   * decisions made
   * requirements discovered or changed
   * ideas generated
   * questions remaining
   * work completed
   * next steps
